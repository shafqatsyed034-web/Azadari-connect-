# Azadari Connect — Live Kafla Module

This module is the UI/logic prototype for the Live Kafla feature.

## Current prototype
- Live/Offline status toggle
- Current location placeholder
- Next stop
- ETA
- Route
- Organizer contact button

## Production implementation
The map and real GPS tracking still need:
- Google Maps SDK / Maps Compose
- Location permission flow
- Foreground location service for organizer
- Secure backend (e.g. Firebase)
- Realtime location updates
- Route/ETA service
- Organizer authentication
- Admin verification

The prototype does NOT transmit a real device location yet.
